# Typography test fixtures

These unmodified fonts are redistributed under the accompanying SIL Open Font
License 1.1 (`OFL.txt`). Copyright belongs to The Noto Project Authors.
They are test data, not installed fonts or runtime dependencies.

Source: <https://github.com/notofonts/noto-fonts>, commit
`ffebf8c1ee449e544955a7e813c54f9b73848eac` (retrieved 2026-09-19):

- `hinted/ttf/NotoSans/NotoSans-Regular.ttf`, SHA-256
  `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`
- `hinted/ttf/NotoSansArabic/NotoSansArabic-Regular.ttf`, SHA-256
  `ceea25b464a656dc3b26849bab9356740401af62aedf1bfa8b7f0d9b75925b1b`

Together these fixtures cover Latin shaping/ligatures, combining marks, Arabic
shaping, mixed-direction text and private-collection fallback. Tests assert
geometry and semantic invariants rather than platform-dependent glyph snapshots.
The two Noto fonts are static; variable axes use the additional fixture below.

Variable-axis coverage uses the unmodified `AmstelvarAlpha-VF.ttf` (128,312 bytes),
Copyright 2016 The Amstelvar Project Authors, under `AmstelvarAlpha-OFL.txt`.
Source: <https://github.com/google/fonts>, commit
`f2bd09badbc763d8757951d52deec29da27e85fb`, path
`ofl/amstelvaralpha/AmstelvarAlpha-VF.ttf` (retrieved 2026-09-19).
SHA-256: `8064db0a8d839ae41296252291acb8e4deffab64dddfb55485b0180420568626`.
The variable-font test compares `wdth` and `wght` configurations.

Color-glyph coverage uses the unmodified `test_glyphs-glyf_colr_1.ttf` (21,568
bytes), from <https://github.com/googlefonts/color-fonts>, commit
`0046ea4c3b69e9fbbe464c2594816894e3aa5e4b`, path
`fonts/test_glyphs-glyf_colr_1.ttf` (retrieved 2026-09-19). This synthetic font is
generated by the repository's `config/test_glyphs-glyf_colr_1.py` and is covered
by its Apache License 2.0 (`ColorFonts-APACHE.txt`). No emoji artwork is included.
SHA-256: `8aa611b1ca97044ac6f13dc982fde29256612f0a5acc6ef47ca541a7a5b99b28`.
The test uses U+F0100, the upstream `linear_repeat_0_1` gradient glyph, to check
multicolor RGBA rendering and A8 opacity independence. This exercises COLRv1;
bitmap, SVG and other color font formats are not covered by these fixtures.
